# Синтезированный план разработки TerminalControl для одного разработчика

Этот план объединяет чёткие критерии готовности из спецификации и простую последовательность шагов из вашего плана. Он оптимизирован для работы в одиночку, без лишних встреч и ритуалов.

Базовые принципы (для себя)
Каждый этап заканчивается рабочим и проверяемым результатом.

Тесты пишутся до кода (хотя бы минимальные: один юнит-тест на новую функцию).

V1.0 — только то, что имеет высокий/средний приоритет по FR. PTY, 256 цветов, альт. буфер — отложены.

Критерий перехода — выполнен чек-лист этапа, все проверки зелёные.

## Этап 0. Фундамент (1 день)
Цель: создать проект, базовый контрол, настроить тесты и CI.

Создать библиотеку классов .NET 8, добавить ссылки на Avalonia 11.x.

Добавить класс Terminal : TemplatedControl.

Написать минимальный XAML-шаблон (пустой ScrollViewer + ItemsControl).

Настроить xUnit, Avalonia.Headless, BenchmarkDotNet.

Настроить GitHub Actions для сборки на Windows, macOS, Linux (smoke-тест: контрол создаётся).

Создать пример приложения (samples/DemoApp) для ручного тестирования.

✅ Проверка: проект собирается на всех трёх ОС, пример запускается, окно пустое.

## Этап 1. Виртуализированный вывод текста (без ANSI) — 2 дня
Цель: отображать много строк быстро и без утечек памяти (FR-3, NFR-1, NFR-2).

Внутренний буфер: кольцевая очередь (List<T> + MaxHistoryLines по умолчанию 10000).

Свойство Lines как IReadOnlyList<TerminalLine> (пока TerminalLine = string).

Метод AppendLine(string text) — добавляет строку, обрезает историю.

ItemsControl с VirtualizingStackPanel, привязанный к Lines.

Автоматическая прокрутка вниз при добавлении (если пользователь не скроллил вверх).

Нагрузочный тест: 50 000 строк, замер FPS и памяти.

✅ Проверка:

Добавление 1000 строк/сек → FPS ≥60.

Память после 100 000 строк ≤30 МБ.

Прокрутка не лагает.

## Этап 2. Базовый ANSI: цвета и стили (2–3 дня)
Цель: поддержка цветов (3/4 бита), bold, italic, underline (FR-1 — High).

Создать класс TerminalLine с полем IReadOnlyList<StyledRun> (стиль + текст).

Написать парсер AnsiParser.Parse(string text, CurrentStyle) → возвращает список StyledRun.

Поддержать коды: \x1b[31m (красный), \x1b[1m (bold), \x1b[3m (italic), \x1b[4m (underline), \x1b[0m (сброс).

Рендеринг: в ItemsControl использовать TextBlock с инлайн-стилями или кастомный OnRender (пока можно через Run в TextBlock).

Юнит-тесты для парсера (каждый код + комбинации).

UI-тест: добавить цветной текст, сравнить со скриншотом (Avalonia.Headless).

✅ Проверка: AppendLine("\x1b[31mRed\x1b[0m Normal") → "Red" красный, остальное стандартное.

## Этап 3. Прокрутка и навигация (1 день)
Цель: удобное управление прокруткой (FR-4).

Полоса прокрутки от ScrollViewer уже есть.

Обработать клавиши: PageUp, PageDown, Home, End, стрелки вверх/вниз.

Обработать колесо мыши.

Методы ScrollToEnd(), ScrollToLine(int).

Событие ScrollChanged (опционально).

✅ Проверка: клавиши перемещают видимую область, колесо работает, после добавления текста можно остаться на месте или уйти вниз (флаг AutoScroll).

## Этап 4. Интерактивный режим и MVVM (2 дня)
Цель: возможность ввода команд и связь с ViewModel (FR-2, FR-10).

Свойство EnableInput (по умолчанию false).

Если EnableInput == true — внизу контрола показывается строка ввода (или редактируемая последняя строка).

Обработка клавиш: печать символов, Backspace, Enter.

При Enter: вызвать InputSubmitted событие (или ICommand SubmitCommand).

Свойство InputText для привязки (двусторонняя).

Пример MVVM: ViewModel с ObservableCollection<TerminalLine> и командой SendCommand.

✅ Проверка: Включить EnableInput, напечатать "help", нажать Enter → событие/команда сработала, строка ввода очистилась.

## Этап 5. Выделение и буфер обмена (2 дня)
Цель: копирование текста, выделение мышью/клавиатурой (FR-5).

Обработка PointerPressed / PointerMoved / PointerReleased для выделения мышью.

Обработка Shift+Arrows для расширения выделения.

Хранить выделенный диапазон (начало-конец).

Ctrl+C / Cmd+C → копировать выделенный текст в Clipboard.

Ctrl+V (если EnableInput) → вставить в строку ввода.

Контекстное меню (ПКМ) с пунктами: Copy, Select All, Clear.

✅ Проверка: Выделить фрагмент мышью, нажать Ctrl+C → в буфере обмена нужный текст.

## Этап 6. Дополнительные возможности (средний приоритет) — 1–2 дня

✅ Проверка: Изменить шрифт — терминал перерисовался. Clear() очистил все строки. Поиск нашёл слово.

✅ Проверка: Переключить тему приложения — цвета терминала изменились. Контраст ≥4.5:1.
