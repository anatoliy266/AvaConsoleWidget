# Технические требования к библиотеке визуального компонента «Терминал» для Avalonia UI (.NET)

## 1. Назначение
Библиотека предоставляет элемент управления (control) для Avalonia UI, эмулирующий текстовый терминал. 
Компонент должен корректно отображать ANSI-форматированный вывод, обрабатывать ввод с клавиатуры, поддерживать интерактивные консольные приложения (в том числе через PTY) 
    и работать на всех целевых платформах Avalonia (Windows, Linux, macOS, браузер через WebAssembly, мобильные платформы).

## 2. Функциональные требования

### 2.1. Эмуляция терминального буфера
- **Основной и альтернативный буферы** – поддержка переключения (например, для `vim`, `mc`, `top`).
- **Ограничение истории** – свойство `MaxHistoryLines` (по умолчанию 1000), автоматическая обрезка старых строк.
- **Прокрутка**:
  - вертикальная прокрутка через скроллбар, колесо мыши, touch-жесты;
  - свойство `AutoScrollToBottom` (включено по умолчанию);
  - при ручной прокрутке вверх авто-прокрутка отключается до достижения низа пользователем.

### 2.2. Поддержка ANSI escape-последовательностей
- **Цвета и стили**:
  - 4-битные (16 цветов), 8-битные (256 цветов), 24-битные (True Color);
  - атрибуты: жирный, курсив, подчёркнутый, мигающий, инверсный, скрытый, зачёркнутый.
- **Управление курсором**:
  - перемещение, сохранение/восстановление позиции;
  - показ/скрытие курсора, изменение формы (блок, подчёркивание, вертикальная черта).
- **Очистка экрана и строк** – полная очистка, очистка от курсора до конца/начала экрана/строки.
- **Вставка/удаление строк и символов** в произвольной позиции.

### 2.3. Обработка пользовательского ввода
- **Клавиатурные события**:
  - обычные символы (с учётом раскладки);
  - управляющие клавиши (Enter, Backspace, Tab, Esc);
  - стрелки, Home, End, PageUp, PageDown, Insert, Delete;
  - комбинации с Ctrl, Alt, Meta (например, Ctrl+C, Ctrl+D).
- **Режим raw input** – возможность получать сырые последовательности клавиш без обработки (для TUI-приложений).
- **Буфер обмена**:
  - копирование выделенного текста в системный буфер;
  - вставка текста из буфера обмена (Ctrl+V, Shift+Insert, правая кнопка мыши).
- **История команд** – хранение введённых строк с навигацией по стрелкам Вверх/Вниз (опционально, может быть реализована на уровне приложения, но компонент может предоставлять хранилище).

### 2.4. Управление размером (resize)
- Автоматическое изменение количества колонок и строк при изменении размера контрола.
- Событие `SizeChanged` с новыми значениями `Columns` и `Rows`.
- Метод `Resize(cols, rows)` для программного изменения размера.

### 2.5. API для разработчика (Avalonia-стиль)
- **Запись вывода**:
  - метод `Write(string data)` и `Write(ReadOnlySpan<byte> data)` – поддерживает частичные последовательности;
  - метод `WriteLine(string text)` – добавляет перевод строки.
- **Ввод данных**:
  - событие `InputReceived` (или `OnInput`) – передаёт строку с введёнными данными (можно использовать `Observable<string>`);
  - возможность привязать команду для обработки строк (`Command` + `CommandParameter`).
- **Управление состоянием**:
  - метод `Clear()` – очистка экрана;
  - метод `Reset()` – полный сброс всех состояний (цвета, стили, курсор, буферы);
  - методы `Focus()` / `Unfocus()`.
- **Доступ к содержимому**:
  - метод `GetText()` – получить весь текст буфера;
  - метод `GetSelectedText()` – выделенный текст;
  - свойство `CursorPosition` (Point).
- **Привязка данных**:
  - зависимое свойство `Content` для прямого связывания с выводом (односторонняя);
  - свойство `InputCommand` для MVVM-обработки ввода.

### 2.6. Стилизация и темы
- Поддержка **тем** через стандартную систему стилей Avalonia:
  - возможность задать цвета фона, текста, курсора, выделения;
  - поддержка динамической смены темы (Light/Dark).
- **Шрифт** – моноширинный, с возможностью задания `FontFamily`, `FontSize`, `FontWeight`.
- **Курсор** – настройка цвета, формы, периода мигания.
- **Полоса прокрутки** – стандартная или кастомизируемая через стили.

### 2.7. Дополнительные возможности (опционально)
- **Распознавание ссылок** – кликабельные URL (событие `UrlClicked`).
- **Поддержка изображений** – Sixel или Kitty protocol (хотя бы через пользовательские отрисовщики).
- **Drag-and-drop** – вставка пути файла при перетаскивании.
- **Поиск** – встроенный поиск с подсветкой (метод `FindNext(string text)`).

## 3. Нефункциональные требования

### 3.1. Производительность
- **Виртуализация строк** – рендеринг только видимой области (как `VirtualizingStackPanel`).
- **Дифференциальная отрисовка** – обновление только изменённых ячеек.
- Асинхронная обработка больших объёмов вывода без блокировки UI.
- Работа с историей >10 000 строк без потери производительности.

### 3.2. Кроссплатформенность
- Полная поддержка Windows, Linux, macOS.
- Работоспособность в браузере через WebAssembly (Avalonia.Web).
- Поддержка мобильных платформ (Android, iOS) с учётом сенсорного ввода.

### 3.3. Доступность (A11y)
- Реализация интерфейсов автоматизации (AutomationPeer) для скринридеров.
- Навигация с клавиатуры (Tab, стрелки) без потери фокуса.
- Контрастность по умолчанию – WCAG AA.

### 3.4. Интеграция с процессами
- Вспомогательный класс `TerminalProcess` для запуска shell-процесса (bash, cmd, powershell) с перенаправлением ввода/вывода.
- Поддержка псевдотерминала (PTY) на Unix и ConPTY на Windows.
- События `ProcessStarted`, `ProcessExited`.

## 4. Пример использования (XAML + code-behind)

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:term="clr-namespace:TerminalControl;assembly=TerminalControl">
    <Grid>
        <term:TerminalControl x:Name="Terminal"
                              FontSize="14"
                              FontFamily="Courier New"
                              Theme="Dark"
                              AutoScrollToBottom="True"
                              InputCommand="{Binding SendCommand}"/>
    </Grid>
</Window>




Спецификация требований к элементу управления Terminal

Проект: Библиотека контролов для Avalonia UI (C#)
Версия документа: 1.0
Целевой фреймворк: .NET 8+, Avalonia 11.x
Тип элемента: Пользовательский контрол (Control / StyledElement)

1. Введение
Элемент управления Terminal предназначен для отображения, стилизации и взаимодействия с текстовым интерфейсом терминала в кроссплатформенных Avalonia-приложениях. Контрол предоставляет готовую инфраструктуру для:
- Вывода логов, результатов команд, REPL-интерфейсов
- Базовой эмуляции терминала с поддержкой ввода
- Интеграции с внешними процессами/потоками через MVVM
Контрол распространяется как NuGet-пакет или исходный код в составе библиотеки.

6. UI/UX и стилизация
- Поддержка Avalonia Style/Theme из коробки
- Кастомизация через ControlTheme:
  <Style Selector="local|Terminal">
      <Setter Property="Background" Value="{DynamicResource TerminalBackground}" />
      <Setter Property="Foreground" Value="{DynamicResource TerminalForeground}" />
      <Setter Property="CursorColor" Value="{DynamicResource TerminalCursor}" />
  </Style>
- Курсор: мигающий (BlinkRate), статичный, скрытый
- Контекстное меню (по ПКМ): Copy, Select All, Clear, Search...
- Минимальный размер: 300x200, автоматическое масштабирование при Window.Resize
- Поддержка ThemeVariant.Dark / ThemeVariant.Light без перезагрузки
